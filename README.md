# O Jardim das Emoções

Aplicativo de bem-estar emocional para ajudar você a registrar sentimentos, cuidar do seu jardim virtual e acompanhar sua jornada de autocuidado.

![Ícone do app](app/src/main/ic_launcher-playstore.png)

## Baixe na Play Store

- Link direto: https://play.google.com/store/apps/details?id=com.ojardimdasemocoes

## O que você encontra no app

- Diário emocional para registrar como você está se sentindo.
- Seleção de humor com emoções como Feliz, Triste, Estressado e Cansado.
- Conselheiro emocional com mensagens de apoio baseadas no seu humor.
- Jardim virtual interativo com ações como regar, podar e adubar.
- Música de fundo com controle de áudio (ligar/desligar).
- Tela com links para apoio psicológico.

## Como usar

1. Abra o app e acesse a tela principal.
2. Entre no Diário e registre seu momento.
3. Escolha seu humor para receber mensagens do Conselheiro.
4. Use as ferramentas para cuidar do seu jardim virtual.
5. Acompanhe sua evolução de forma leve e acolhedora.

## Privacidade

- Seus dados do diário e estado do jardim são armazenados localmente no dispositivo.
- O app não vende nem compartilha seus dados pessoais.
- Você pode consultar a Política de Privacidade dentro do próprio aplicativo.
